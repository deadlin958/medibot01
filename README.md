# Clinical Chatbot — Multimodal Medical Q&A System

A safe, evidence-based, multimodal clinical chatbot powered by **PubMedQA**,
**GPT-4o**, **LangChain**, and **ChromaDB**.

> ⚠️ **Disclaimer:** This system is for general guidance only. It does not
> replace a qualified medical professional. Always consult a doctor.

---

## Quick Start

### 1. Install dependencies
```bash
pip install -r requirements.txt
```

### 2. Set your API key
```bash
copy  .env
# Edit .env and add your OPENAI_API_KEY
```

### 3. Build the vector index (one-time, ~10 min)
```bash
python scripts/build_index.py
```

### 4. Run the backend
```bash
python backend/app.py
```
Backend runs at `http://localhost:5000`

## API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| POST | `/api/greet` | Start a new session, get greeting + first triage question |
| POST | `/api/chat` | Send a message; handles triage then RAG Q&A |
| POST | `/api/reset` | Reset a session to restart triage |
| POST | `/api/image-query` | Upload image + question for multimodal Q&A |
| GET  | `/health` | Health check |

### /api/chat request body
```json
{ "session_id": "user123", "message": "I have a headache" }
```

### /api/image-query form fields
- `image`: image file (JPEG, PNG, WebP, GIF, BMP — max 10 MB)
- `question`: text question about the image
- `session_id`: session identifier

## Safety Design

- 🛡️ Emergency keyword detection — triggers instant escalation
- 🔒 Hard-coded disclaimer appended to every response
- 🚫 No diagnostic language — only cautious phrasing
- 📋 Structured pre-consultation triage before any medical guidance
- 🏥 PubMedQA-only evidence — no hallucinated citations

## Architecture

```
User → Fast API API
         ├── Triage State Machine (5-step)
         │
         └── RAG Pipeline
               ├── ChromaDB Retriever (sentence-transformers/all-MiniLM-L6-v2)
               ├── Prompt Builder (safety guardrails baked in)
               └── GPT-4o (gpt-4o, temp=0.2)

Image → GPT-4o Vision → Text Description → RAG Pipeline
```
